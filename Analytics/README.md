# Skill Network Analysis Dashboard

Django-based analytics platform for analyzing and visualizing the temporal evolution of skills in the European labor market using dynamic networks.

---

## Features

- Temporal skill evolution analysis
- Louvain community detection
- Dynamic network visualization
- Heatmaps and skill path analysis
- Interactive dashboard interface
- Community evolution tracking

---

## Technologies Used

- Python
- Django
- Pandas
- NetworkX
- JavaScript
- HTML/CSS

---

## Project Structure

- `core/` → Django configuration
- `dashboard/` → Main dashboard application
- `scripts/` → Data processing and network analysis scripts

---

## Analysis Methods

This project includes:
- Temporal network analysis
- Louvain community detection
- Centrality analysis
- Skill similarity analysis
- Community evolution tracking
